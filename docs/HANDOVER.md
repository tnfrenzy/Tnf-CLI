## 2. Quy tắc làm việc (bắt buộc)
- Commit: `git -c user.name=dev -c user.email=agent@example.com commit -m "…" -m "Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>"` (máy không có identity git toàn cục). Commit nhỏ theo từng mục, làm trực tiếp trên `main`.
- Mỗi bước kết thúc bằng bằng chứng chạy thật ghi vào `docs/PROGRESS.md` (mục mới dưới "Trạng thái hiện tại", rồi cập nhật mục trạng thái). Không tuyên bố xong khi chưa chạy. Đừng nối `npm test | tail` bằng `&&` rồi commit: pipe nuốt mã thoát, phải xem dòng "Tests … passed".
- Sửa tài liệu bằng script: **không** dùng `String.replace(anchor, text)` khi `text` có thể chứa `$` (JS hiểu `$'`, `$&`); dùng `split/join`, hàm thay thế `() => text`, hoặc công cụ Edit. Máy **không có Python**.
- Ngữ cảnh: không đọc lại toàn bộ PROGRESS/SPIKE-RESULTS; không mở `stream.jsonl` lớn. Vượt 200k token: tóm tắt vào PROGRESS, commit, chuyển phiên mới không hỏi.
- Công cụ Bash/PowerShell của Claude Code Desktop diễn giải `\r`/`\n` trong lệnh thành ký tự thật: không vá mã có escape bằng heredoc hay `node -e`; dùng công cụ Edit/Write. File `.ps1`/`.iss` có tiếng Việt phải giữ **BOM UTF-8** (Write tool không thêm BOM → ghi lại bằng `[IO.File]::WriteAllText(p, text, UTF8Encoding $true)`).
- Defender/AMSI chặn script PowerShell dùng `CopyFromScreen` ("ScriptContainedMaliciousContent"); chụp màn hình bằng `SendKeys {PRTSC}` + `Get-Clipboard -Format Image` thì được. Ảnh chụp toàn màn hình có thể lộ cửa sổ khác của người dùng → cắt trước khi đưa vào `docs/screens/`.
- Trình duyệt nhúng: `resize_window mobile` bị xóa khi `navigate` → gọi lại sau navigate; ảnh chụp đôi khi cũ sau click (DOM đúng) → cuộn rồi chụp lại, hoặc click theo `ref`; không mở được WebSocket tới localhost (UI có thăm dò REST); đổi `#token=` trên cùng trang không nạp token mới → navigate với query khác hoặc F5.
- Chạy Claude thật chỉ khi brief cho phép; trước đó kiểm hạn mức (`mcp__ccd_session_mgmt__get_usage`, 5-hour < 60 %). Demo không tốn token: `.\scripts\start.ps1 -Demo -NoOpen` (+ env `FAKE_CLAUDE_FIXTURE=<abs path>`, `FAKE_CLAUDE_GIT_COMMIT=1` cho run coding, `FAKE_CLAUDE_AUTH=none` để giả "chưa đăng nhập").

## 3. Những gì đã có (kiểm lại trong mã trước khi tin)
- API (`src/server/http.ts`): projects (`GET/POST /api/projects`, `/validate`), runs (`POST /api/runs {prompt, project, kind, model, role_models, inbox_stage}`, `GET /api/runs/:id` có `kind/worktree_path/branch/base_sha/verdicts/commits/changed_files/worktree_exists/repo_path/base_branch/stream_path/inbox`), `/events`, `/report`, `/artifacts/<rel>`, `/artifacts.zip`, `/stream`, `/cancel`, `/followup`, `/open-dir`, `/cleanup-worktree`, `POST /api/inbox` + `POST /api/runs/:id/inbox`, **`/api/status` (có `auth`, `auth_error`, `claude_path`, `claude_version`, `claude_error`, `rate_limit`)**, WS `/ws/runs/:id` + `/ws/overview` (token qua subprotocol `tnf-token.<token>`).
- Bảo mật: bind `127.0.0.1`; Origin/Host chỉ localhost + `server.allowedOrigins`; token header bắt buộc; CSP `connect-src` tự thêm origin đường hầm.
- Lõi: `src/core/` — `config.ts` (`REPO_ROOT` suy từ vị trí `dist/core/config.js` → bản cài dùng `app/` làm root, `dataDir ../data`), `run-manager.ts` (`resolveClaude`, `claudeVersion`, `authStatus`), `claude-locator.ts` (`locateClaude(explicit, env)`), `git.ts`, `permissions.ts`, `inbox.ts`, `zip.ts`, `run-store.ts`, `stream-parser.ts`, `version.ts`.
- UI (`ui/src/`), một màn hình: `App.tsx` không còn tab; bảng trái `components/LeftPanel.tsx`; cảnh thành phố `office/CityScene.tsx` + `office/city-sim.ts` (tầng = project); các trang cũ (Lệnh, Lần chạy, Lịch sử, Thư viện, Cài đặt) gói trong `components/Modal.tsx`; trạng thái popup ở `popup.ts` với hash `#/runs/<id>`; `office/OfficeShell.tsx` nối `components/IsoOffice.tsx` (`office/iso/*`) vào popup tầng; trang Lệnh có project picker, loại run, đính kèm và **`components/ClaudeGuide.tsx`** khi thiếu/chưa đăng nhập; `pages/OfficePage.tsx` (văn phòng 2D cũ) đã xóa ở 0.14.0.
- Bộ vai: `config/roles-coding.json` có 6 vai coding (analyst, planner, critic, implementer, qa, debug); `config/roles-catalog.json` có 23 vai mẫu.
- Đóng gói/cài đặt: `scripts/package.ts` (`npm run package` → `build/app/`; `packagedConfig()` viết lại `controller.json`), `scripts/installer.ts` (`npm run installer`, tìm ISCC), `installer/setup.iss`, `installer/tray.ps1` (khay; `-Demo`, `-Port`, `-NoOpen`), `installer/stop.ps1`, `installer/make-icon.ps1` → `tnf.ico`. README mục "Cài đặt bằng Setup.exe".
- Project mẫu: `spike` → `D:\tnf-claude-workspace\spike-repo`; `controller` → `D:\tnf-claude-controller`. Worktree spike/demo cũ còn tồn trong `D:\tnf-claude-workspace\worktrees` và `spike-repo` (nợ (6)).
- Khởi động dev: `.\scripts\start.ps1 [-Demo] [-NoOpen] [-Port]`, dừng `.\scripts\stop.ps1`; CLI `npm run tnf -- …`.
